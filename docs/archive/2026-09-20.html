🧠 Data Science Topic of the Day

🎓 SHAP (SHapley Additive exPlanations)

Making any model's predictions explainable — one feature at a time.

What It Is

SHAP is a unified framework for interpreting machine learning model outputs, rooted in cooperative game theory. It assigns each input feature a 'Shapley value' — the average marginal contribution that feature makes to the prediction across all possible combinations of features. Unlike simple feature importance scores, SHAP values are locally accurate (they explain a single prediction, not just global averages), consistent (a feature that matters more always gets a higher value), and model-agnostic (they work on XGBoost, neural nets, linear models, anything). The result is a principled answer to the question every business stakeholder eventually asks: 'Why did the model say that?'

How It Works

1. GAME THEORY FOUNDATION — Imagine each feature as a 'player' in a coalition game. The prediction is the 'payout.' Shapley values calculate each player's fair share by iterating over every possible subset of features, measuring the prediction with and without that feature, and averaging the difference. With p features there are 2^p subsets — computationally explosive, so SHAP uses smart approximations. 2. TREESHAP (exact, fast for tree models) — For gradient boosted trees and random forests, the TreeSHAP algorithm computes exact Shapley values in polynomial time by exploiting the tree structure. This is the variant you'll use most often with XGBoost or LightGBM in B2B scoring. 3. KERNELSHAP (model-agnostic) — For any black-box model, KernelSHAP uses a weighted linear regression over sampled feature coalitions to approximate Shapley values. Slower than TreeSHAP but universal. 4. DEEPSHAP (for neural nets) — Combines DeepLIFT with Shapley values to propagate attributions backward through network layers efficiently. 5. OUTPUT TYPES — (a) Local explanation: a waterfall chart showing exactly which features pushed a single prediction above or below the baseline. (b) Global explanation: a beeswarm/summary plot aggregating SHAP values across all records to show overall feature importance and directionality. (c) Dependence plots: how a single feature's SHAP value changes as its raw value changes, revealing non-linear effects and interactions. 6. ADDITIVE PROPERTY — The fundamental guarantee: baseline_prediction + sum_of_all_SHAP_values = actual_model_output. This makes SHAP values fully auditable — the math always closes.

When To Use

— CREDIT & RISK DECISIONS: Regulations (ECOA, GDPR, EU AI Act) require adverse action notices and explainability for automated decisions. SHAP gives you the exact sentence: 'Credit declined primarily due to high Days Beyond Terms (+0.18 score impact) and thin trade line history (+0.12).' — MODEL DEBUGGING: A feature contributing unexpectedly high SHAP values is often a proxy leak or data quality issue — SHAP surfaces it immediately. — SALES PRIORITIZATION: When reps challenge why an account scored low, SHAP lets you show them the three specific factors dragging the score down, which converts model skeptics into model users. — FEATURE SELECTION: Prune your feature set using mean absolute SHAP values — far more reliable than default Gini importance in tree models, which is biased toward high-cardinality features. — MONITORING: Track the distribution of SHAP values for key features over time. A shift in SHAP distributions — even before accuracy degrades — is an early warning of data drift.

🎯 Worked Example — D&B Context

D&B's Opportunity Scoring Model for Account Expansion: D&B builds a LightGBM model predicting which existing customers are likely to expand wallet share in the next 90 days (the Buydex buying window signal). The model uses 40+ features: Paydex trend (6-month delta), DUNS corporate family tree depth, employee growth rate, SIC sector momentum, days-since-last-purchase, current product tier, and firmographic signals. SCENARIO — A rep questions why 'Acme Manufacturing' (a Fortune 500 account) scored only 34/100 for expansion despite being a long-tenured customer. A standard feature importance chart just says 'Paydex delta is the #1 global feature' — useless for this specific account. WITH SHAP — You run TreeSHAP on Acme's record and generate a waterfall chart: Baseline score (average across all accounts): 51 + Corporate family tree has 12 subsidiaries → +9 (upsell surface area) + SIC sector (Industrial Machinery) trending up → +6 − Paydex score dropped 14 points in 60 days → −18 (payment stress signal) − Last purchase was 210 days ago → −4 Final predicted score: 44 (model output matches: 51+9+6−18−4 = 44, rounding aside) ACTION — The rep now knows this isn't a relationship problem — it's a cash flow stress signal. Instead of pitching an upsell, the Account Intelligence agent flags Acme for the collections risk workflow AND recommends offering extended payment terms as the re-engagement angle. The explainability changed the commercial play entirely. SCALE — D&B runs this across 2M scored accounts monthly. Aggregated SHAP beeswarm plots feed back into the model governance dashboard, and compliance teams use the local waterfall outputs as automated adverse action documentation — satisfying both the sales team and the legal team with one framework.
