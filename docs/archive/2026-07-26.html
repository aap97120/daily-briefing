🧠 Data Science Topic of the Day

🎓 Bayesian Inference

Stop asking 'is this statistically significant?' — start asking 'what should I believe, and how strongly?'

What It Is

Bayesian inference is a framework for updating beliefs about the world as new evidence arrives. Instead of producing a single point estimate ('the conversion rate is 3.2%'), it produces a full probability distribution over possible values ('here is how likely every conversion rate is, given what we've seen'). It formalises the intuition that prior knowledge matters: if you already know B2B SaaS trials rarely convert above 8%, that belief should influence — but not override — what you learn from a new 200-row experiment. The output is a 'posterior distribution': your prior belief reshaped by the data. Everything flows from Bayes' theorem: P(hypothesis | data) ∝ P(data | hypothesis) × P(hypothesis). In plain English: your updated belief equals how well the data fits the hypothesis, multiplied by how strongly you believed the hypothesis before seeing the data.

How It Works

1. DEFINE A PRIOR: Encode existing knowledge as a probability distribution. For a conversion rate you might use a Beta(2, 20) prior — a weak belief that rates are low but not zero. Priors can be 'uninformative' (flat, letting data dominate) or 'informative' (encoding real domain knowledge). 2. SPECIFY A LIKELIHOOD: Choose a statistical model that describes how data is generated given the hypothesis. For binary outcomes (converted / did not convert) this is usually a Binomial likelihood. For continuous revenue figures, a Normal or log-Normal. 3. COMPUTE THE POSTERIOR: Multiply prior by likelihood, then normalise. For conjugate pairs (Beta prior + Binomial likelihood) this has a clean closed form: Beta(α + successes, β + failures). For complex models, use Markov Chain Monte Carlo (MCMC) or Variational Inference to approximate the posterior numerically. Libraries: PyMC, Stan, NumPyro. 4. MAKE DECISIONS FROM THE POSTERIOR: Read off credible intervals ('there is a 95% probability the true rate lies between 2.1% and 5.8%'), compute the probability that variant A beats variant B directly, or propagate uncertainty into downstream models. Key distinction from frequentist stats: a Bayesian 95% credible interval literally means 'I am 95% confident the parameter is in this range.' A frequentist 95% confidence interval does NOT mean that — it means 'if I repeated this experiment infinitely, 95% of such intervals would contain the true value,' which is a subtly different and less intuitive statement.

When To Use

— SMALL SAMPLES: B2B datasets are almost always small. You may have 40 enterprise prospects in a new vertical. Bayesian methods squeeze signal from thin data by incorporating priors rather than throwing up a 'not enough data' error. — SEQUENTIAL / ALWAYS-ON EXPERIMENTS: Update beliefs as each new lead converts rather than waiting for a fixed sample size. This is Bayesian A/B testing — no peeking problem, no arbitrary stopping rules. — WHEN UNCERTAINTY IS THE PRODUCT: If a salesperson asks 'how confident are you that this account will expand in Q3?', a point prediction ('67%') is less useful than a distribution ('most likely 55–75%, but fat tail up to 90% if their Series B closes'). — INCORPORATING DOMAIN KNOWLEDGE: D&B has decades of payment behaviour data. That institutional knowledge belongs in the prior, not discarded. If Paydex history says firms in this SIC code default at ~4%, start there rather than pretending you know nothing. — HIERARCHICAL MODELLING: Model sales rep performance across regions simultaneously — each rep informs every other rep's estimate via shared hyper-priors, avoiding both extremes of 'treat every rep identically' and 'treat every rep in isolation.'

🎯 Worked Example — D&B Context

SCENARIO — Bayesian Win-Rate Estimation for a New Vertical: D&B is pushing into the Climate-Tech vertical with 12 enterprise AEs. After 60 days, they have 34 opportunities and 6 closed-won deals — a raw win rate of 17.6%. Sales leadership asks: is this vertical worth scaling? Classic frequentist answer: 'We don't have enough data to say anything significant.' Bayesian answer: Start with an informative prior drawn from D&B's historical win rates across comparable new verticals: Beta(5, 20) — encoding a prior belief centred around 20% but with real uncertainty. Update with the observed data (6 wins, 28 losses): Posterior = Beta(5+6, 20+28) = Beta(11, 48). Now compute: Posterior mean = 11/(11+48) = 18.6%. 95% credible interval: roughly 10% – 30%. Probability the true win rate exceeds the 15% 'go/no-go' threshold: ~71%. Decision: not conclusive enough to commit a full territory build-out, but strong enough to greenlight 3 more AEs for 90 days and re-evaluate. EXTENSION — Hierarchical across regions: Run the same model simultaneously across 5 regions. Each region's win rate estimate is pulled toward the global mean (partial pooling), so a rep with only 4 deals in APAC gets a regularised, more honest estimate rather than an absurd 0% or 100%. This directly feeds D&B's Territory & Market Planning agent archetype — the posterior distributions become probabilistic inputs to quota-setting rather than fabricated point forecasts. The Explainability First principle is satisfied too: you can show a CFO the full posterior and say exactly what assumptions (the prior) you encoded and exactly how the data shifted them.
